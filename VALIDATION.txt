검증 결과

- node --check: JavaScript 문법 통과
- 모의 DOM/API 검증 통과: 입력 검사, 프로필 표시, 안전한 텍스트 및 URL 처리, 페이지 추가, 저장소 실패 후 같은 페이지 재시도, 404, 빈 목록, 일반 403, 요청 제한 403/429, 대기 중 요청 차단, 네트워크 실패, 오래된 응답 무시, 인증 헤더 미사용
- HTML/CSS/JS 파일은 빌드 없이 배포 가능하며 자산 경로는 상대 경로입니다.
